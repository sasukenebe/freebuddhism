# Complete Candana Sutta Nipāta conversion review

The owner requested public access to the complete conversion for independent
external review. This publication is a conversion draft, not approval of a new
canonical edition, its mapping or a full human proofread.

Review address: https://freebuddhism.org/reviews/candana-sutta-nipata/

## Presentation and build

The review starts with one original PDF link, one complete converted-book link,
an unchanged raw-text download and a short external-review request. Individual
suttas have converted-text links and plain PDF page references, not 73 copies of
the same PDF link. There is no JavaScript reader or embedded PDF object.

The build uses only the exact frozen source paths and hashes declared in
metadata/source-manifests/candana-snp-review.json. It cannot publish a different
cached draft. All 152 generated review files are separately included in the
strict webroot file-set and link checks. They are not added to canonical readers,
translator defaults or collection-download archives. Existing homepage and
reader outputs must remain byte-identical during the targeted release.

The public conversion.json lists source hashes, all section/page intervals and
generated output hashes without private filesystem paths. The review request
asks for page-specific differences and explicit coverage, rather than treating
a sample or converter agreement as a full-book approval.

Full build, browser and live release checks are retained with deployment evidence.
